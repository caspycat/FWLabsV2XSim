# V7 simulator configuration

The former dotted-parameter reference has been superseded by the
[V7 TOML configuration reference](toml-configuration-v7.md).

V7 is a rewrite: legacy `.cfg` files, V6 field aliases, dotted name-value
overrides, and the `simParams`/`appParams`/`phyParams`/`outParams` input model
are not compatibility contracts.
