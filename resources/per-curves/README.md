# Packet-error-rate curves

These calibrated packet-error-rate assets are the V7 runtime copy of the
curves retained under `old_src/PERcurves` for historical reproducibility.
Runtime configurations and publication workflows must reference this
`resources/per-curves` tree, not `old_src`.

The migration copied all 80 files byte-for-byte. No curve samples, filenames,
or MATLAB data were regenerated or numerically transformed.
